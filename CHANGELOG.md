# Changelog

## [1.0.0] - 2026-11-13

* **First release with downloads:** an AppImage for any distribution (Gear
  Lever installs and updates it) and an RPM for Fedora. Neither needs the
  cloned repository any more; `install.sh` still works for running from
  the source.
* Nine tools: hammer, chain-saw, machine gun, flame-thrower,
  colour-thrower, phaser, stamp, termites and washing gun. Works on X11 and
  Wayland.
